# Weerapat Engineering Platform

เวอร์ชันระบบจริงพร้อมฐานข้อมูล D1 และหลังบ้านที่ `/admin`

## สิ่งที่ทำได้

- เข้าสู่ระบบด้วย ChatGPT ก่อนเปิดหลังบ้าน
- ผู้ใช้คนแรกของ Site แบบ Private จะถูกบันทึกเป็นเจ้าของระบบ
- เพิ่มและแก้ไขวิชาหลัก หัวข้อโปรเจกต์ และคลิปบทเรียน
- วางลิงก์ YouTube และลิงก์ภาพปกได้จากแบบฟอร์ม
- ตั้งราคา สถานะร่าง/เผยแพร่ และล็อกคลิป
- เก็บข้อมูลถาวรใน D1 ไม่ใช่ localStorage
- เตรียมตาราง enrollment และ entitlement สำหรับสิทธิ์นักเรียน

## ความปลอดภัย

เริ่มเผยแพร่ Site แบบ Private ก่อน เพื่อให้เจ้าของเข้าสู่ระบบเป็นคนแรก หลังจากบันทึกเจ้าของแล้วจึงค่อยกำหนดผู้ชมเพิ่มเติม ห้ามเปิด Public ก่อน bootstrap เจ้าของระบบ

## การพัฒนาในอนาคต

การอัปเดต Site project เดิมจะรักษา URL เดิมไว้ สามารถเพิ่มระบบชำระเงินจริง อัปโหลดไฟล์เข้า R2 และเชื่อมโดเมนส่วนตัวภายหลังได้
